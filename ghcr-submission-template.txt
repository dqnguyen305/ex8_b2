Bai 3 - Build va push payment-service len GHCR

GitHub username: <TEN_NGUOI_DUNG_GITHUB_VIET_THUONG>
Package URL: <URL_PACKAGE_GHCR_SAU_KHI_PUSH_THANH_CONG>

Quyen PAT su dung:
- Personal access token (classic), chi cap scope write:packages de push image.
- Khong ghi PAT vao file nay. Khi docker login hoi Password, dan PAT vao terminal.

Cac lenh PowerShell da chay (thay username viet thuong truoc khi chay):

cd .\demo
$env:GITHUB_USERNAME = "<ten-github-viet-thuong>"
$env:GHCR_IMAGE = "ghcr.io/$($env:GITHUB_USERNAME)/payment-service:1.0.0"
docker login ghcr.io --username $env:GITHUB_USERNAME
docker build -t payment-service:1.0.0 .
docker tag payment-service:1.0.0 $env:GHCR_IMAGE
docker push $env:GHCR_IMAGE
docker image inspect $env:GHCR_IMAGE --format '{{.Id}}'

Ket qua:
- Ghi lai ket qua docker login va docker push thanh cong.
- Mo URL package o tren va xac nhan tag 1.0.0 hien thi.
- Xoa hoac thay cac placeholder bang thong tin thuc te truoc khi nop.
- Khong nop PAT, mat khau, hoac noi dung credential trong file/anh chup.
